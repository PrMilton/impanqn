# IMPA NQN

Proyecto web unificado.

- Gestor: https://prmilton.github.io/impanqn/nqn.html
- Visualizador de Liturgia: https://prmilton.github.io/impanqn/liturgia.html
- Editor de Liturgia: integrado en el gestor; archivo editor-liturgia.html.
- Encuesta de miembros: https://prmilton.github.io/impanqn/encuesta.html
- Cartelera pública: https://prmilton.github.io/impanqn/cartelera.html
- Administración de cartelera: administrar-cartelera.html

Conserva los proyectos Firebase y datos existentes de cada aplicación. No contiene una exportación nueva del padrón ni de contabilidad. GitHub Pages: rama main, carpeta raíz.

Procedencia: PrMilton/impa (gestor, encuesta, mapa y mayordomía), PrMilton/Liturgia (editor y visualizador), PrMilton/cartelera-pastoral (cartelera pública). Los módulos educativos de impa no forman parte de este traslado.
